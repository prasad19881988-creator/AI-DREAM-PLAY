# AI Dream Play — Starter

A mobile-friendly static prototype for an AI character story app.

## What works now
- Responsive landing page and character cards
- 18+ entry confirmation screen (not a legally sufficient age-verification system)
- Character categories: Romance, Drama, Family, Mystery and Custom
- Demo chat with sample replies
- No API keys or paid services required to preview

## Important limitations
This is a front-end prototype. Replies are sample/demo text, not generated by a real AI model. It does not yet create real voice or video, store user accounts, or process payments.

## Next production steps
1. Add a secure backend/API route for text AI; never put private API keys in `app.js`.
2. Choose a video/voice provider that explicitly permits the intended fictional adult-oriented use and check its current pricing and content rules.
3. Add server-side age checks, consent/safety controls, abuse reporting, privacy policy, terms, deletion controls, and secure authentication.
4. Add database persistence and usage limits before public launch.
5. Integrate payments only after the service and legal requirements are reviewed.

## Deploy as a static site
Upload `index.html`, `styles.css`, and `app.js` to a static hosting service. Keep `README.md` for setup notes.
